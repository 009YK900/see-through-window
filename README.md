# see-through-window

把任意窗口变成**半透明、置顶**的参考浮层，**默认仍然可以正常操作它**。

按 `Ctrl+Alt+G`，正在看的那个窗口就变成一层半透明浮层叠在工作画面上，
仍然可以点它、滚动它；再按一次，原样还原。全程不用切窗口。

![演示：把写满内容的窗口调成半透明，露出背后的文档](docs/demo.gif)

> 画面为 2 倍速。窗口从完全不透明逐渐变透明，背后的正文慢慢显出来，
> 而鼠标依旧能正常操作这个窗口。

```
       ┌─────────────────────────────┐
       │  教程视频（半透明、置顶）     │  ← Ctrl+Alt+G
       │  ┌───────────────────────┐  │
       │  │  你的软件（照常用鼠标） │  │  ← 浮层默认可交互
       │  └───────────────────────┘  │
       └─────────────────────────────┘
         想让鼠标"穿过去"时再按 Ctrl+Shift+Alt+X
```

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 |
| Python | 3.8 及以上 |
| 依赖 | **无**。只用标准库，不需要 `pip install` |

建议使用 [python.org](https://www.python.org/downloads/) 安装的 Python。
微软商店版是 MSIX 打包应用，Windows 拒绝它使用经典托盘 API，
**托盘图标不会出现**（其余功能正常）。

## 运行

在终端里进入项目目录，然后：

```bash
python see_through_window.py
```

不想要控制台窗口：

```bash
pythonw see_through_window.py
```

也可以双击 `start-see-through-window.vbs` 静默启动。

停止运行：按 `Ctrl+Shift+Alt+Q`，或在终端里 `Ctrl+C`。
两种方式都会**先还原所有被改过的窗口**再退出。


## 使用步骤

1. 先用鼠标点一下要操作的那个窗口，让它在前台
2. 按 `Ctrl+Alt+G`
3. 再按一次 `Ctrl+Alt+G` 还原

如果焦点在终端上，按热键作用到的就是终端自己。

## 关于「不透明度」

提示条里的数字是**不透明度（opacity）**，不是透明度：

| 显示 | 含义 |
|---|---|
| 100% | 完全不透明，和原样一样 |
| 70% | 七成不透明，背后能透出三成（参考窗默认值） |
| 20% | 很淡，几乎只看得到轮廓 |

**数字越小越透明。** 用 `Ctrl+Alt+[` / `Ctrl+Alt+]` 调整，下限 20%。

## 热键

| 热键 | 作用 |
|---|---|
| `Ctrl+Alt+G` | **参考窗模式**：置顶 + 70% 不透明，鼠标仍可正常操作（再按一次还原） |
| `Ctrl+Alt+T` | 只切换置顶 |
| `Ctrl+Shift+Alt+X` | 点击穿透：浮层不再响应鼠标（可选，默认关；同一时刻只允许 1 个窗口，见下文） |
| `Ctrl+Alt+[` | 更透明（不透明度 -10%） |
| `Ctrl+Alt+]` | 更不透明（不透明度 +10%） |
| `Ctrl+Alt+0` | 还原当前窗口；若前台窗口没被改过，则还原所有窗口 |
| `Ctrl+Shift+Alt+Q` | 退出 |

有托盘图标时，右键托盘 → 还原所有窗口 / 快捷键说明 / 退出。

### 热键被占用怎么办

Windows 的全局热键**先到先得**：如果某个组合已经被别的程序注册，本工具就注册不上，按下去触发的是那个程序。

先检查当前配置的可用性：

```bash
python see_through_window.py --check-hotkeys
```

```
热键可用性检查：C:\...\config.ini

  [可用] Ctrl+Alt+G           参考窗模式（置顶 + 透明，可交互）
  [占用] Ctrl+Alt+T           只切换置顶  <- 被别的程序占用
  ...
```

看到 `[占用]` 就编辑同目录的 `config.ini`（首次运行自动生成）里对应那行，
**重启工具**生效：

```ini
# 同一时刻最多允许几个窗口处于穿透状态
max-through = 1

ghost = ctrl+alt+g
top = ctrl+alt+t
through = ctrl+shift+alt+x
alpha-down = ctrl+alt+[
alpha-up = ctrl+alt+]
reset = ctrl+alt+0
quit = ctrl+shift+alt+q
```

修饰键可任意组合 `ctrl` / `alt` / `shift` / `win`；
主键支持 `a-z`、`0-9`、`f1-f24`、`[ ] ; ' , . / \ - = `` 以及 `space`/`tab`/`enter`/`esc` 等。

启动时终端也会打印每个热键的注册结果，抢不到的标 `[占用]`。

## 目标窗口的限制

- **只作用于前台窗口**：不做窗口列表、不做批量管理
- **跳过**：桌面 / 任务栏、本工具自己的窗口、不可见窗口
- **管理员窗口改不了**：目标窗口若以管理员身份运行，普通权限下无法改其样式，
  会提示「这个窗口改不了样式」
- **GPU 直接呈现的窗口**：少数全屏游戏、部分 Electron/UWP 应用加上分层属性后
  可能变黑或看不出透明，这是系统限制

## 点击穿透的注意事项

- 默认**关闭**，透明浮层始终可以正常点击
- 开启后该窗口点不到鼠标，只能用热键关掉
- `Ctrl+Alt+0` 是保底键：前台窗口没被改过时，它会还原所有窗口

### 默认只允许 1 个窗口穿透

穿透窗口完全没有鼠标入口。如果同时有多个，一旦忘了哪个是哪个，
就只能靠猜窗口来关——所以**默认限制为 1 个**，规则很简单：

> 只要有一个窗口在穿透状态，**无论当前前台是哪个窗口**，
> 按 `Ctrl+Shift+Alt+X` 操作的都是**那一个**。

也就是说它永远不会开第二个。
想把穿透换到另一个窗口，连按两次即可：第一次关掉原来那个，第二次开新的。

上限可以在 `config.ini` 里改：

| 值 | 行为 |
|---|---|
| `1`（默认） | 只允许一个；热键在任何地方都只控制它 |
| `2` 及以上 | 允许这么多个；达到上限后再按会提示"先关掉一个" |
| `0` | 不限制（不建议：穿透窗口点不到，多了很难收拾） |



## 自检

不显示窗口（只在末尾闪一下提示条），验证 Win32 这一层是否正常工作：

```bash
python see_through_window.py --selftest
```

检查项：窗口创建、扩展样式置位与还原、分层透明度、热键注册、
托盘可用性、提示条绘制、参考窗模式状态机、单一穿透限制、配置解析、崩溃自愈。

## 不做什么

- 不是窗口管理器：不做布局、分组、位置记忆
- 不注入目标进程，不读取窗口内容，不截屏
- 不改系统设置，不写注册表
- 不联网

## 原理


1. **改扩展样式** — `SetWindowLongPtrW(GWL_EXSTYLE)` 上加/去三个位：
   `WS_EX_TOPMOST`（置顶）、`WS_EX_LAYERED`（允许半透明）、
   `WS_EX_TRANSPARENT`（鼠标穿透）
2. **设不透明度** — `SetLayeredWindowAttributes(hwnd, 0, alpha, LWA_ALPHA)`
3. **收热键** — `RegisterHotKey`，消息循环里处理 `WM_HOTKEY`

干净的还原需要两步：第一次改动前把窗口**原始的**扩展样式存下来，
还原时写回去——否则会把窗口原本就有的属性一起抹掉。
